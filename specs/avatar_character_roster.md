# Avatar Tactical Card Game — Character Roster

**Purpose:** A balanced candidate roster for the Avatar tactical card game. This is a character-pool proposal, not a final balance sheet: each character should eventually have distinct attributes, a passive trait, and a signature card package.

## Roster principles

- **25 characters total**, split evenly across five gameplay classes: Water, Earth, Fire, Air, and Non-bending.
- **5 characters per class (20% each)**.
- Draws from both animated series: *Avatar: The Last Airbender* (ATLA) and *The Legend of Korra* (LOK), so the Air class has enough distinct characters.
- Tiny emoji-style glyphs are placeholders for UI icons. They are not official character art and can later be replaced with custom portraits or original silhouettes.
- Class means the character's primary gameplay identity. Avatars are assigned to their most defining base class for roster accounting; Aang is listed under Air, while his four-element access and Avatar State should be represented by special mechanics.

## At-a-glance balance

| Class | Count | Gameplay identity |
|---|---:|---|
| Water | 5 | Control, healing, flexible targeting, binds |
| Earth | 5 | Durability, terrain shaping, counters, displacement |
| Fire | 5 | Pressure, burst damage, aggression, combo chains |
| Air | 5 | Mobility, evasion, redirection, repositioning |
| Non-bending | 5 | Precision, gadgets, feints, anti-bending tactics |
| **Total** | **25** | **5 per class** |

## Cross-class roster considerations

### Avatar State

- Aang is the only character in this roster with the Avatar State.
- Keep Avatar State separate from normal Air-class abilities and from Focus.
- Its build-up, activation cost, duration, bonuses, and immediate-loss condition should be implemented by the shared battle engine, not hard-coded into individual card effects.
- The roster may later add other Avatars from different eras. They should be clearly marked as Avatars and balanced around the same core risk rules, with character-specific variations only where necessary.

### Team-building constraints to test

- Prevent teams from stacking only high-control characters without giving opponents counterplay.
- Make sure each class has at least one focused attack, one defensive option, and one positional or utility technique across its card pool.
- Avoid class hard-counters: each class should have viable answers to every other class.
- Test mixed teams as well as mono-class teams.
- Consider restricting teams to one Avatar-capable character in standard play.

## Suggested MVP implementation order

1. **Core six:** Aang, Katara, Toph, Zuko, Sokka, Azula — a familiar and varied initial test roster.
2. **Expand to 15:** add Iroh, Suki, Ty Lee, Bumi, Pakku, Tenzin, Lin, Kuvira, Ming-Hua.
3. **Complete the 25-character pool:** add Hama, Unalaq, Ghazan, Jeong Jeong, P'Li, Jinora, Zaheer, Kai, Mai, Asami.
4. Tune each character through playtests before adding more cards or complex passives.

## Reference scope

Character and bending classifications are based on the animated *Avatar: The Last Airbender* and *The Legend of Korra* series. The roster's gameplay roles and mechanics are original design proposals for this game, not canon abilities or official game data.
